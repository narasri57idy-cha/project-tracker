📋 วิธีเชื่อมระบบกับ Google Sheets

1. เปิด Google Sheets → Extensions → Apps Script
2. วางโค้ด Code.gs → Save → รัน "ติดตั้งระบบ"
3. Deploy → New deployment → Web app → Execute as: Me → Anyone
4. คัดลอก URL มาวางด้านล่าง
